# Память проекта: Структура Setl

## Контекст
Страница иерархии подразделений компании Setl. Сайт на 1С-Битрикс. Мобильной версии не будет.

## Принятые решения

### Поиск сотрудника
- Дропдаун со списком совпадений при вводе
- После выбора — плавный скролл/панорама к карточке в дереве + подсветка узла
- Пользователь видит человека в контексте иерархии, а не изолированно

### Дерево
- Интерактивное, expand/collapse по клику
- Breadcrumb-навигация: `Компания → Отдел → Команда → Имя`, каждый уровень кликабелен
- Карточка: минимум данных, детали по hover или в боковой панели
- Цветовое кодирование по подразделениям — обсудить

## Отложено на будущее

### Страница профиля сотрудника (отдельная страница)
- Кнопка **"Показать в дереве"** — возвращает в иерархию с якорем на этом человеке
- Breadcrumb с кликабельными уровнями

## Компоненты карточек
- `card-head` — большое фото, должность, ФИО (топ-руководитель)
- `card-assistant` — меньше фото, "Административный помощник", ФИО; на том же уровне что и руководитель, но визуально меньше
- `card-person` — обычный сотрудник
- `card-division` — узел-подразделение
- `card-division-link` — подразделение со ссылкой на отдельную страницу (визуально отличается)

## Структура навигации (JS-переходы, один HTML-файл)
```
[УРОВЕНЬ 0] Раздаточная
  4 директора + 3 логотипа (SetlGroup / ПН / SetlTech) + Бэк-офис-строка (sticky под заголовком)

[УРОВЕНЬ 1] SetlGroup → 4 блока (Строительный / Архбюро / Калининград / Упр.недвижимостью)
  + кнопка "Список юридических лиц"

[УРОВЕНЬ 2] Бесконечный холст (zoom/pan как Miro) с деревом
  Особый узел "Департамент строительства" → ведёт дальше

[УРОВЕНЬ 3] Дерево по объектам: Рук → Деп → Рук → Зам → ЖК → РП → Очереди
```

## Особенности дерева
- В одном блоке может быть 2 топ-менеджера сразу
- Сотрудник без дирекции: стрелка идёт через пустой блок вниз к командам
- Порядок элементов настраивается в 1С
- Фото сотрудника — показывать/скрывать настраивается в 1С
- Hover на подразделение → окошко с функционалом + административный помощник

## Технические данные сайта
- Сайт: 1С-Битрикс, встраиваемся в готовый шаблон
- Контентная область: 1568px, padding 40px с каждой стороны = 1488px рабочая
- Левый сайдбар ~330px (навигация сайта)
- Наша страница: Компания → Структура
